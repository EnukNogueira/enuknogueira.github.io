# Portfólio Pessoal — Enuk Nogueira

Portfólio pessoal desenvolvido para apresentar minha trajetória, projetos, estudos e conhecimentos na área de tecnologia.

O site também funciona como um projeto prático de desenvolvimento web, utilizando HTML, CSS e JavaScript sem frameworks externos.

---

## Sobre o projeto

Este portfólio foi criado para reunir em um único lugar meus principais projetos, conhecimentos e informações profissionais.

Além de apresentar meu trabalho, o projeto também foi uma oportunidade para praticar desenvolvimento front-end, organização de código, consumo de API e criação de uma interface responsiva.

---

## Funcionalidades

- Apresentação pessoal e profissional
- Seção de projetos
- Links para os respectivos repositórios no GitHub
- Integração com a API do GitHub
- Download do currículo
- Links para redes profissionais
- Interface responsiva
- Animações e efeitos visuais
- Tema visual inspirado em ficção científica

---

## Tecnologias utilizadas

- **HTML5** — estrutura da aplicação
- **CSS3** — estilização, responsividade e animações
- **JavaScript (ES6+)** — interações e lógica da aplicação
- **GitHub REST API** — obtenção de informações dos repositórios
- **Canvas API** — efeitos visuais
- **Web Audio API** — efeitos sonoros
- **SVG** — elementos gráficos e ícones

---

## Estrutura do projeto

- `index.html` — estrutura principal do portfólio
- `style.css` — estilos, layout, responsividade e animações
- `script.js` — lógica e interações da aplicação
- `favicon.svg` — ícone do site
- `github-icon.svg` — ícone utilizado na interface
- `curriculo.pdf` — currículo profissional

---

## Desenvolvimento

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro, sem frameworks ou bibliotecas externas.

Durante o desenvolvimento foram utilizados recursos nativos do navegador para criar diferentes elementos da interface, incluindo:

- Animações com CSS
- Efeitos visuais utilizando Canvas
- Sons utilizando Web Audio API
- SVGs para elementos gráficos
- Consumo da API REST do GitHub

O projeto também foi utilizado para explorar o uso de ferramentas de Inteligência Artificial durante o desenvolvimento, principalmente na geração, revisão e refatoração do código.

---

## Como executar

O projeto não possui dependências externas.

Para executar localmente:

1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Também é possível acessar a versão publicada através do GitHub Pages.
